# 🍔 Foody Zone

Foody Zone is a modern food browsing web application where users can explore different food items categorized by meal types such as Breakfast, Lunch, and Dinner. It features a clean UI, category-based filtering, and a responsive design.

---

## 🌐 Live Demo (Overview)

👉 https://vercel.com/abhinav-a0s-projects/foodyzone



---

## 🚀 Features

* 🔍 Search food items
* 🍳 Filter by categories (All, Breakfast, Lunch, Dinner)
* 🖼️ Beautiful food cards with images
* 💲 Price display for each item
* ⚡ Fast and responsive UI
* 🌙 Dark-themed modern design

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/abhinav-a0/foodyzone.git
cd foodyzone
```

---

### 2️⃣ Setup Backend

```bash
cd server
npm install
npm run dev
```

👉 Runs on: http://localhost:5000

---

### 3️⃣ Setup Frontend

```bash
cd app
npm install
npm run dev
```

👉 Runs on: http://localhost:5173

---

## 🔗 API Integration

```js
fetch("http://localhost:5000/api/foods")
```

---

## 🎯 How It Works

* Backend serves food data
* Frontend fetches & displays items
* Category buttons filter data
* Search filters items dynamically
